# ESP32 FlatBuffers Implementation Plan

WebSocket + FlatBuffers backend implementation for ESP32 using ESP-IDF.

## Status: PENDING

## Dependencies

- ESP-IDF (latest stable)
- `flatcc` or `flatbuffers` C/C++ library
- Shared schema: `frontend/proto/pidkiln.fbs`

---

## Overview

Replace all HTTP endpoints and JSON WebSocket messages with binary FlatBuffers over WebSocket.

**Architecture:**
```
┌─────────────┐    WebSocket    ┌─────────────┐
│   Browser   │ ◄────────────► │    ESP32    │
│ flatbuffers │   FlatBuffer   │   flatcc    │
│     npm     │    messages    │             │
└─────────────┘                └─────────────┘
```

---

## Library Choice

### Option A: flatcc (C)

- Pure C, designed for embedded
- Generates C code from `.fbs` schema
- Zero-copy reader, builder API for writing
- Smaller footprint (~10-15KB code)

```bash
# Generate C code
flatcc -a pidkiln.fbs
```

### Option B: flatbuffers (C++)

- Official Google library
- C++11 required
- Header-only
- Slightly larger but more familiar API

**Recommendation:** `flatcc` for smaller footprint and C compatibility.

## ESP-IDF WebSocket Setup

### Binary Frame Handling

```c
#include "esp_http_server.h"

// WebSocket handler for binary frames
static esp_err_t ws_handler(httpd_req_t *req) {
    if (req->method == HTTP_GET) {
        // Upgrade to WebSocket
        return ESP_OK;
    }
    
    httpd_ws_frame_t ws_pkt;
    memset(&ws_pkt, 0, sizeof(httpd_ws_frame_t));
    ws_pkt.type = HTTPD_WS_TYPE_BINARY;
    
    // Get frame length
    esp_err_t ret = httpd_ws_recv_frame(req, &ws_pkt, 0);
    if (ret != ESP_OK) return ret;
    
    // Allocate buffer
    uint8_t *buf = malloc(ws_pkt.len);
    ws_pkt.payload = buf;
    
    // Receive frame
    ret = httpd_ws_recv_frame(req, &ws_pkt, ws_pkt.len);
    if (ret == ESP_OK) {
        handle_flatbuffer_message(buf, ws_pkt.len, req);
    }
    
    free(buf);
    return ret;
}
```

## Message Handling

### Decoding Client Messages

```c
#include "pidkiln_reader.h"  // Generated by flatcc

static void handle_flatbuffer_message(const uint8_t *buf, size_t len, httpd_req_t *req) {
    // Verify buffer
    if (!PIDKiln_ClientEnvelope_verify_as_root(buf, len)) {
        send_error(req, 0, "Invalid message");
        return;
    }
    
    // Zero-copy read
    PIDKiln_ClientEnvelope_table_t envelope = PIDKiln_ClientEnvelope_as_root(buf);
    uint32_t request_id = PIDKiln_ClientEnvelope_request_id(envelope);
    
    switch (PIDKiln_ClientEnvelope_message_type(envelope)) {
        case PIDKiln_ClientMessage_StartCommand: {
            PIDKiln_StartCommand_table_t cmd = 
                (PIDKiln_StartCommand_table_t)PIDKiln_ClientEnvelope_message(envelope);
            int segment = PIDKiln_StartCommand_segment(cmd);
            int minute = PIDKiln_StartCommand_minute(cmd);
            
            bool success = start_program(segment, minute);
            send_ack(req, request_id, success, NULL);
            break;
        }
        
        case PIDKiln_ClientMessage_StopCommand:
            stop_program();
            send_ack(req, request_id, true, NULL);
            break;
            
        case PIDKiln_ClientMessage_HistoryRequest: {
            PIDKiln_HistoryRequest_table_t req_msg = 
                (PIDKiln_HistoryRequest_table_t)PIDKiln_ClientEnvelope_message(envelope);
            int64_t since = PIDKiln_HistoryRequest_since_ms(req_msg);
            int limit = PIDKiln_HistoryRequest_limit(req_msg);
            
            send_history_response(req, request_id, since, limit);
            break;
        }
        
        // ... handle other message types
    }
}
```

## State Broadcasting

### Timer-Based Broadcasts

```c
static void state_broadcast_task(void *arg) {
    while (1) {
        kiln_state_t state;
        get_current_state(&state);
        
        // Build and send to all connected clients
        broadcast_state(&state);
        
        vTaskDelay(pdMS_TO_TICKS(1000));  // 1 second interval
    }
}

static void broadcast_state(const kiln_state_t *state) {
    // Build FlatBuffer once
    uint8_t buffer[512];
    size_t size = build_state_message(buffer, sizeof(buffer), state);
    
    // Send to all WebSocket clients
    for (int i = 0; i < MAX_CLIENTS; i++) {
        if (clients[i].connected) {
            send_binary_frame(clients[i].fd, buffer, size);
        }
    }
}
```

## Firmware Upload Handling

### Chunked Upload

```c
case PIDKiln_ClientMessage_UploadFirmwareChunk: {
    PIDKiln_UploadFirmwareChunk_table_t chunk = 
        (PIDKiln_UploadFirmwareChunk_table_t)PIDKiln_ClientEnvelope_message(envelope);
    
    uint32_t offset = PIDKiln_UploadFirmwareChunk_offset(chunk);
    flatbuffers_uint8_vec_t data = PIDKiln_UploadFirmwareChunk_data(chunk);
    size_t data_len = flatbuffers_uint8_vec_len(data);
    bool is_last = PIDKiln_UploadFirmwareChunk_is_last(chunk);
    
    if (offset == 0) {
        // Start OTA update
        esp_ota_begin(...);
    }
    
    // Write chunk
    esp_ota_write(..., flatbuffers_uint8_vec_at(data, 0), data_len);
    
    if (is_last) {
        // Finalize and reboot
        esp_ota_end(...);
        esp_restart();
    }
    
    send_ack(req, request_id, true, NULL);
    break;
}
```

## Memory Considerations

### Buffer Sizes

| Message Type | Typical Size | Max Size |
|--------------|--------------|----------|
| State | ~100 bytes | 256 bytes |
| Ack | ~20 bytes | 64 bytes |
| HistoryResponse (100 points) | ~2KB | 8KB |
| ProgramContent | varies | 10KB |

### Static Allocation Strategy

```c
// Pre-allocated buffers for common messages
static uint8_t state_buffer[256];
static uint8_t ack_buffer[64];
static uint8_t history_buffer[8192];

// Builder with static buffer (no malloc)
flatcc_builder_t builder;
flatcc_builder_init(&builder);
flatcc_builder_set_buffer(&builder, state_buffer, sizeof(state_buffer));
```
